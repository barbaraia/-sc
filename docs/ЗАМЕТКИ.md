# Заметки по работе

## Что проверял

1. Посмотрел типы признаков, пропуски и распределение целевой переменной.
2. Построил график зависимости стоимости от медианного дохода района.
3. Проверил модели относительно простой медианной константы.
4. Сделал разбиение по географическим ячейкам: близкие записи легко дают излишне оптимистичную оценку при случайном train/test split.

## На что обратил внимание

- Значения `MedHouseVal` измеряются в сотнях тысяч долларов; RMSE=0.4 означал бы примерно 40 000 USD на данных 1990 года.
- Сложная модель должна выигрывать у baseline; иначе дополнительная сложность не оправдана.
- Координаты полезны, но результаты могут сильно зависеть от того, какие районы оказались в тесте.

## Если продолжать

Сравнить 2–3 размера географической сетки, оценить качество по регионам, построить residual plot. Отдельно сделать обычный random split только для иллюстрации разницы в оценке (не выбирать по нему победителя задним числом).
