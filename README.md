# Прогноз стоимости жилья в Калифорнии

Учебный проект по **регрессии**. Задача — попробовать предсказать медианную стоимость жилья по характеристикам районов. Использую датасет California Housing из `scikit-learn` (данные переписи 1990 года, а не сегодняшние цены на недвижимость).

Мне было интересно не просто обучить несколько моделей, а разобраться, насколько результат зависит от способа разбиения данных. В датасете есть координаты, поэтому объекты из соседних районов могут быть похожи.

## Что есть в проекте

- [`notebooks/01_housing.ipynb`](notebooks/01_housing.ipynb) — основная работа по шагам: просмотр данных, графики, baseline, сравнение моделей и проверка качества;
- `src/housing/` — тот же эксперимент в виде запускаемого Python-кода;
- `tests/` — небольшие проверки разбиения, обработки данных и расчёта метрик;
- [`docs/ЗАМЕТКИ.md`](docs/ЗАМЕТКИ.md) — выводы, ограничения и что попробовать дальше.

## Какие модели сравниваю

`DummyRegressor` как простая отправная точка, Ridge, Random Forest и HistGradientBoosting. При установленном `catboost` дополнительно пробую CatBoost. Сравнение выполняю по **RMSE**, отдельно смотрю MAE и R².

**Важный момент:** объекты из одной географической ячейки не должны одновременно попадать в train и test. Препроцессинг обучается только на обучающих данных. Такой тест сложнее обычного случайного разделения, но он тоже не гарантирует независимость соседних районов.

## Как запустить

Нужен Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -e '.[dev,boosting]'
```

Сначала можно открыть `notebooks/01_housing.ipynb` в Jupyter или VS Code. Для запуска всей последовательности из консоли:

```bash
python -m housing.eda --source california --output-dir reports
python -m housing.train --source california --output-dir artifacts
python -m pytest -q
```

Датасет загружается автоматически при первом запуске (нужен интернет). Сохранённые результаты появятся в `artifacts/metrics.json`, `artifacts/model_comparison.csv` и `artifacts/predicted_vs_actual.png`.

Если интернета нет, можно проверить только работу кода на **синтетических данных**:

```bash
python -m housing.train --source synthetic --no-catboost
```

Метрики синтетической проверки **не являются результатом на California Housing**.

## Ограничения

Цены относятся к переписи 1990 года, верхняя граница целевой переменной обрезана, а географическое разбиение не равно проверке на данных из будущего. Для реального сервиса понадобятся более свежие данные и отдельная оценка качества.

Источник: [California Housing в scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_california_housing.html). Проект создан для обучения с использованием AI-помощника; перед использованием в портфолио стоит выполнить эксперименты, сохранить результаты и разобраться в каждом шаге.
