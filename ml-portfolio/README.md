# ML portfolio — two reproducible learning projects

This directory contains two separate, ready-to-publish repository folders:

1. [`housing-price-prediction`](housing-price-prediction/) — 1990 California Housing, grouped geographic holdout, regression pipelines and model comparison.
2. [`churn-risk-api`](churn-risk-api/) — IBM Telco Customer Churn, stratified CV, validation-selected business threshold, SQL feature example, FastAPI and Docker.

Each directory has independent dependencies, unit tests, a README, license and clean `.gitignore`.

**Note:** These projects were created as learning portfolio examples. The dataset-download paths require internet access for a real-data run. The code also supports explicitly labelled synthetic smoke tests for execution without internet. Any real dataset metrics must be generated and documented after a verified run; do not present demo metrics as real data or claim prior professional deployment.
